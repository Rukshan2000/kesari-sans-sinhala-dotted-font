# Kesari Sans 1.0

A dotted tracing font for children learning to write Sinhala, made from **UN-Bindumathi** by Pushpananda Ekanayaka, the font used on helakuru.lk. Each letter is drawn as evenly spaced round dots along its centre line. Sinhala shaping works as it does in the original font: conjuncts, rakaransaya (ක්‍ර), yansaya (ක්‍ය), repaya (ර්‍ක) and vowel signs (කෙ, කෝ, කෞ).

**Font file:** `kesari-sans.ttf`
**Font name in apps:** Kesari Sans

## Install
- **macOS:** double-click the .ttf file, then click *Install Font*.
- **Windows:** right-click the .ttf file, then choose *Install*.

Then choose **Kesari Sans** in Word, LibreOffice or Pages. For tracing, a size of 24–48 pt works well.

## Coverage
80 of the 91 Sinhala code points. Not included: candrabindu (U+0D81) and the Sinhala Lith digits (U+0DE6–0DEF), because the original font doesn't have them.
